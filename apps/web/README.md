# @nb-corp/nb-speak-web

Source directory for the warm paper-ink `nb-speak` Live IM Split-Stage Playground (`src/`), statically exported to `../../docs` for GitHub Pages (`https://nb-corp.github.io/nb-speak/`).

```bash
# Compile browser protocol engine & sync src/ -> ../../docs/
npm run build

# Serve ../../docs/ locally on http://127.0.0.1:4173
npm run serve
```

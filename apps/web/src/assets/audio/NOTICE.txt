AI-Synthesized Demo Audio Notice
================================

The static `.mp3` voice-note demonstration clips in this directory (`sre-en.mp3`,
`handoff-en.mp3`, `sre-zh.mp3`, `handoff-zh.mp3`) are AI-generated synthetic
speech created solely to demonstrate the `nb-speak` playground voice-note UI:

- English clips (`*-en.mp3`): Synthesized via ElevenLabs (`eleven_v4`) using
  official premade platform voices under a paid Creator subscription.
- Chinese clips (`*-zh.mp3`): Synthesized via Alibaba Cloud Model Studio
  (`qwen-audio-3.1-tts-plus`) using official preset system voices.

No real person's voice was cloned or impersonated.

              1. 安装 chat-human 技能
              
            
    
            
    npx skills add NB-Corp/nb-speak
    
          
    

          
    
            
    
              2. 启动 OpenAI / SSE 桥接服务
              
            
    
            
    npx --yes github:NB-Corp/nb-speak serve --port 18090
    
          
    

          
    
            
    
              3. 一键挂载至 DSH
              
            
    
            
    npx --yes github:NB-Corp/nb-speak-dsh --apply --profile web

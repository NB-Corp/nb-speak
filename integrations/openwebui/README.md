# OpenWebUI Filter — NB Speak

Single-file OpenWebUI Function (`Filter`) that brings `chat-human` mobile IM rhythm and pipe-table cleanup to **OpenWebUI**.

## Import in 10 Seconds

1. Open **OpenWebUI -> Workspace -> Functions -> + (New Function)**.
2. Paste or import [`nb_speak_filter.py`](./nb_speak_filter.py), save, and toggle it **On** (globally or per model).
3. `enable_voice_notes` is **off by default** (`False`).
